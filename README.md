# ジルアーナマチャラ亭 メニュー・オーダーシステム

## 概要

「ジルアーナマチャラ亭」は、鶏肉食べ放題をメインとした大衆居酒屋風の飲食店（架空）です。
このシステムでは、お客さんが受付で人数・年齢・性別・飲み放題の有無・アレルギーを登録し、メニューを見て注文し、会計まで行えます。

- 食べ放題：90分・1人 2,500円（来店者全員）
- 飲み放題：+1,000円／人（来店者ごとに選択。20歳未満はソフトドリンクのみの飲み放題）

## 起動方法

インストールは不要です。ブラウザ（Chrome / Edge など）があれば動きます。

```
git clone https://github.com/kdt26aie40009-max/restaurant-order.git
cd restaurant-order
start index.html
```

`start index.html` の代わりに、エクスプローラーで `index.html` をダブルクリックしても起動できます。

### 使用した技術

- HTML / CSS / JavaScript（ブラウザだけで動く Web アプリ）
- サーバー・データベース・外部ライブラリは使用しない

| ファイル | 役割 |

## データ設計

### 保存方法

| データ | 保存先 | 理由 |
|---|---|---|
| メニュー | `menu.js` に直接書く | 商品の追加・変更が簡単。`index.html` をそのまま開いても読み込める（JSON ファイルは `file://` で開くとブラウザの制限で読み込めないため使わない） |
| 注文データ・会計情報 | ブラウザの localStorage | 再読み込みしても消えない。インストール不要で、講師の PC でもそのまま動く |
| 人気ランキング | localStorage の会計確定済みデータから集計 | 別に保存する必要がない |

localStorage には次の 2 つのキーで保存します。開発者ツール（F12）→「アプリケーション」→「ローカル ストレージ」で中身を確認できます。

| キー | 中身 |
|---|---|
| `jiru_current_order` | 会計前の注文（受付〜会計確定まで）。会計を確定すると削除する |
| `jiru_orders` | 会計確定済みの注文の一覧（人気ランキングの集計に使う） |

注意：localStorage のデータは、そのPCのそのブラウザにだけ残ります。初めて起動したときは会計確定済みの注文がないため、人気ランキングは「まだ注文がありません」と表示されます。

### データの形

| データ | 項目 |
|---|---|
| メニュー | メニューID、品名、価格、カテゴリ、アレルギー |
| 来店・注文情報 | 注文ID、注文日時、人数、注文状態（注文中／終了） |
| 来店者情報（1人ずつ） | お客さんID、年齢、年代、性別、飲み放題の有無 |
| 注文内容（1品ずつ） | メニューID、メニュー名、数量、単価、小計 |
| ドリンクの注文内容（1品ずつ） | お客さんID、メニューID、メニュー名、数量、単価、飲み放題か単品か |
| 会計情報 | 食べ放題料金、飲み放題料金、一品料理料金、デザート料金、単品ドリンク料金、合計金額、会計確定日時 |
| 店員呼び出し（1回ずつ） | 呼び出し日時 |

## 画面と機能

### 画面構成

画面は 4 つで、①→②→③→④の順に進みます（③から②へ戻れる。④のあとは新しい注文を始められる）。

**① 受付画面（最初に表示）**

- 店名と食べ放題の案内（90分・2,500円）
- 人数の入力と、来店者 1 人ずつの「年齢・性別・飲み放題を付けるか」の登録
- アレルギーの指定（卓全体・9 種類のチェックボックス）
- 「注文をはじめる」ボタン

**② 注文画面（メイン）**

- 上部：店名と「店員呼び出し」「会計へ」ボタン
- 左側：カテゴリのタブで切り替えるメニュー一覧。各品に品名・価格・アレルギーを表示し、数量を指定して注文する
- 右側：上から「おすすめ」「人気ランキング」「注文済み一覧」
- ドリンクを注文するときだけ「誰の分か」を選ぶ

**③ 会計確認画面**

- 食べ放題・飲み放題・一品料理・デザート・単品ドリンクの内訳と合計金額
- 「戻る」「会計を確定」ボタン

**④ 会計完了画面**

- 合計金額と「ご利用ありがとうございました」
- 新しい注文を始めるボタン

### 要件と機能の対応

| No | 要件 | どの機能で満たしたか |
|---|---|---|
| 1 | 店名表示 | 受付画面と注文画面の上部に「ジルアーナマチャラ亭」を表示 |
| 2 | メニュー表示 | 5 カテゴリ・全 25 品を、注文画面のタブで切り替えて表示。各品に価格を表示 |
| 3 | 注文 | 数量（1〜99）を指定して注文。会計前なら注文済み一覧で数量を減らして取り消せる（0 で取り消し） |
| 4 | 注文データの記録 | 来店者情報・注文内容・会計情報を localStorage に保存 |
| 5 | おすすめ機能 | 来店者の年代（料理 2 品）と性別・年齢（ドリンク 1 品）からおすすめを表示。あわせて会計確定済みの注文から鶏肉の人気ランキング TOP3 を表示 |
| 6 | 会計 | 食べ放題・飲み放題・一品料理・デザート・単品ドリンクを合計して表示。飲み放題は人ごとに選択 |
| 7 | 入力チェック | 人数・年齢・数量の範囲と形式、20歳未満のアルコールをチェック。不正な入力ではエラーメッセージを出し、システムは止まらない |
| 8 | アレルギー対応 | 各品にアレルギーを表示。指定したアレルギーを含む品はメニューとおすすめから非表示 |

### おすすめ機能の詳細

1人につき 3 品をおすすめします。アレルギーで除外された品はおすすめから外します（代わりの品は補いません）。

| 年代 | おすすめ料理 |
|---|---|
| 10代（0〜9歳を含む） | 鶏の唐揚げ、フライドポテト |
| 20代 | 手羽先唐揚げ、鶏もも |
| 30代 | せせり、鶏皮ポン酢 |
| 40代 | 砂ずり、枝豆 |
| 50代 | ヤゲン軟骨、鶏ハツ |
| 60代以上 | 鶏もも、キャベツ |

| 性別 | 20歳以上 | 20歳未満 |
|---|---|---|
| 男性 | 生ビール | コーラ |
| 女性 | レモンサワー | オレンジジュース |
| 回答しない | ハイボール | ウーロン茶 |

### 人気ランキングの詳細

- 対象は鶏肉食べ放題メニューのみ
- 会計が確定した注文の「個数」で集計（人数ではない）。会計前に取り消した分は数えない
- 個数の多い順に TOP3 を表示。データがないときは「まだ注文がありません」

### 入力チェックの詳細

| 項目 | 許可する値 | 不可 |
|---|---|---|
| 人数 | 1〜20人の整数 | 0人、21人以上、小数、文字など |
| 年齢 | 0〜120歳の整数 | マイナス、121歳以上、小数、未入力 |
| 注文時の数量 | 1〜99個の整数 | 0個、100個以上、小数、マイナス |
| 注文済み一覧の数量 | 0〜99個の整数（0 は取り消し） | 100個以上、小数、マイナス |
| アルコール | 20歳以上の人の分のみ | 20歳未満の注文、20歳未満のアルコール飲み放題 |

## 自分で決めたこと

| 決めたこと | 理由 |
|---|---|
| 店のコンセプトを「鶏肉食べ放題の大衆居酒屋」にした | 食べ放題・飲み放題があると、会計の計算に工夫が必要になり面白いため |
| 技術は HTML / CSS / JavaScript のみ | `index.html` を開くだけで動き、講師の PC で準備が要らないため |
| 注文データの保存先を localStorage にした | 再読み込みしても消えず、インストールも不要なため |
| メニューを `menu.js` に書いた | 商品の追加が 1 行で済み、`file://` でも読み込めるため |
| 鶏肉食べ放題の価格を「食べ放題（0円）」と表示 | 食べ放題料金に含まれるため。価格がないのではなく 0 円であることを明示する |
| 受付で来店者を 1 人ずつ登録する | 飲み放題・年齢によるアルコール制限・おすすめを人ごとに扱うため |
| ドリンクの注文時だけ「誰の分か」を選ぶ | 飲み放題（0円）と単品（有料）を区別するため。料理は全員の合計で会計するので選ばない |
| 20歳未満はソフトドリンクのみの飲み放題（+1,000円） | 未成年もドリンクの飲み放題を楽しめるようにしつつ、飲酒を防ぐため |
| おすすめは料理を年代、ドリンクを性別・年齢で決める | 6年代×3性別の 18 通りを個別に決めるより分かりやすく、入力を変えるとおすすめが変わるため |
| 0〜9歳は「10代」のおすすめを使う | 年代区分が 10代からのため。子どもにも食べやすい品になっている |
| アレルギーは特定原材料 8 品目＋大豆 | 表示が義務の品目を基準にし、枝豆・醤油に関係する大豆を加えた |
| アレルギーは卓全体で指定し、該当品を非表示 | 同じ卓で料理を取り分けることが多いため。非表示にすると誤って注文しない |
| 焼き鳥は塩のみ | タレ（醤油）に含まれる小麦・大豆を避け、アレルギー表示をシンプルにするため |
| 人気ランキングは鶏肉のみ・会計確定分の個数で集計 | 食べ放題の看板メニューの人気を示すため。取り消された注文を数えないため |
| 取り消しは注文済み一覧で数量を 0 にする | 数量を減らす操作と取り消しを同じ操作でできて分かりやすいため |
| 会計前に再読み込みしても、注文画面から再開する | 会計前の注文も localStorage に保存しているため。誤って再読み込みしても注文が消えない |
| 店員呼び出しボタンを付け、押すと画面に表示して日時を記録する | 居酒屋では追加の取り皿や質問などで店員を呼ぶことが多いため。サーバーがないので別端末への通知はせず、記録を残して確認できるようにした |
| 同じ品の注文は 1 行にまとめる（ドリンクは同じ人・同じ扱いのとき） | 注文済み一覧を見やすくするため。まとめた数量も 99 個までとする |
